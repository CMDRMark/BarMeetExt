# BarMeetExt

Public privacy policy for the **BarMeet** Chrome extension.

## Privacy policy URL

After GitHub Pages is enabled, use:

**https://cmdrmark.github.io/BarMeetExt/**

Paste that URL into:

- Google Cloud → OAuth consent screen → Privacy policy URL
- Chrome Web Store listing → Privacy policy

## Enable GitHub Pages

1. Push this repo to `main`
2. GitHub → **Settings** → **Pages**
3. Source: **Deploy from a branch**
4. Branch: `main` / `/ (root)` → Save

## Files

- `index.html` — policy page (Pages homepage)
- `PRIVACY_POLICY.md` — same content in Markdown
