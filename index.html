BarMeetExt

Official information page for BarMeet, a free Chrome extension for Google Calendar meeting awareness and quick Google Meet links. No account or login is required to read this page.

What BarMeet does

BarMeet helps you stay on top of today’s calendar without opening Google Calendar in a tab. After you install the extension from the Chrome Web Store and choose to connect your Google account inside the extension, you can:

  • See your current or next meeting in the toolbar badge and title
  • Open a popup with Now and Upcoming meetings and join when a link exists
  • Start meeting — create a quick Google Calendar event with Google Meet and copy the join link
  • Block focus time on your calendar (busy, no Meet)
  • Cancel or reschedule events you are allowed to edit
  • Optionally receive local reminders before meetings

BarMeet is a client-side Chrome extension. It does not provide a separate web application or user login on this website.

Get the extension

Install BarMeet from the Chrome Web Store (search for BarMeet or use the listing link from the publisher). Google Calendar access is requested only inside the extension after you click Connect Google Calendar.

OAuth application

The Google Cloud OAuth client used by BarMeet is registered under the application name BarMeetExt. That name refers to this open-source project; the product name shown to users is BarMeet.
